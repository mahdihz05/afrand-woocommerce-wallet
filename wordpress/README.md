# اتصال کیف پول افرند به وردپرس

افزونهٔ `afrand-wallet-bridge` نسخهٔ **1.0.2** روی سایت آزمایشی نصب و فعال شده است. وابستگی آن WooCommerce و افزونهٔ فعال **TeraWallet / WooWallet** است. این اتصال مشتری بدون ایمیل می‌سازد و از متد اصلی `woo_wallet()->wallet->credit()` برای واریز استفاده می‌کند؛ تراکنش در کیف پول اصلی وردپرس قابل مشاهده است.

برای نصب مجدد، پوشهٔ `afrand-wallet-bridge` را ZIP کنید و از بخش افزونه‌های وردپرس بارگذاری و فعال کنید. هنگام ارتقا فقط همین افزونه جایگزین می‌شود. رمز مدیر وردپرس در برنامه یا کد قرار نمی‌گیرد؛ API با کلیدهای موجود WooCommerce احراز هویت می‌کند. کلید به کاربری با `manage_woocommerce` و برای ساخت مشتری با `create_users` نیاز دارد.

مسیرهای محدود اتصال زیر `wc/v3/afrand-wallet` هستند: وضعیت، جست‌وجو و تطبیق مشتری، ساخت مشتری، موجودی/تراکنش‌ها، واریز و بررسی نتیجهٔ یک درخواست. این افزونه مسیر برداشت یا ثبت سفارش ندارد. موبایل ایرانی نرمال می‌شود؛ حساب‌های مبهم رد می‌شوند. ایمیل حساب جدید خالی است و ایمیل ساختگی تولید نمی‌شود.

هر واریز شناسهٔ یکتای پایدار دارد. جدول اختصاصی `<prefix>afrand_wallet_operations` و نشانگر تراکنش اصلی، نتیجه را نگهداری می‌کنند. تکرار درخواست همان نتیجه را برمی‌گرداند و تغییر مبلغ یا مشتری برای همان شناسه رد می‌شود. قطع پاسخ پس از واریز با خواندن تراکنش اصلی بررسی می‌شود؛ نتیجهٔ نامعلوم بدون بررسی دوباره واریز نمی‌شود. جدول عملیات و تراکنش‌های اصلی را هنگام ارتقا/بازگشت نسخه حذف نکنید.

واحد مبلغ از کیف پول اصلی خوانده می‌شود؛ سایت تأییدشده `IRT`، تومان با صفر رقم اعشار است. تبدیل خودکار ریال به تومان وجود ندارد. پیاده‌سازی و API اصلی: [مخزن رسمی TeraWallet](https://github.com/malsubrata/woo-wallet).
